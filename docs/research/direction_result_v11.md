## 참고: 순위 모델 자체 문턱으로 고른 예측 (v9 코인)

예측기는 모델 자체의 문턱으로 "확신 상위 10%"와 "상위 5%"를 표시한다. 순위 모델은 더 많은 예측에 표시를 붙인다.

| | 4시간 순위 | 4시간 v9 | 8시간 순위 | 8시간 v9 |
|---|---|---|---|---|
| 상위 10% 건수 | 48,287 | 28,838 | 45,035 | 30,000 |
| 상위 10% 적중률 | 56.73% | 57.15% | 58.13% | 58.47% |
| 상위 10% 해마다 | 55.5 / 55.2 / 57.7 / 58.3 / 58.6% | | 56.6 / 56.2 / 58.7 / 59.8 / 61.5% | |
| 상위 5% 건수 | 25,426 | 13,176 | 23,221 | 12,898 |
| 상위 5% 적중률 | 57.13% | 58.28% | 58.58% | 60.61% |

- 표시가 붙는 예측이 50 ~ 70% 늘고, 적중률은 0.3 ~ 0.4%p 낮아진다. 상위 5%는 건수가 두 배 가까이 되고 적중률이 1 ~ 2%p 낮아진다.
- 같은 건수로 맞춰 비교하면 적중률이 같다. 즉 순위 모델은 가장 확신하는 예측을 더 잘 맞히는 것이 아니라, **비슷하게 맞는 예측을 더 많이** 찾아낸다.

## 참고: 고른 예측의 방향

- 같은 건수 선택에서 "중간보다 더 오른다"는 예측은 4시간 9%, 8시간 10%뿐이다. 순위 모델이 확신하는 예측의 대부분은 "중간보다 못 오른다"는 쪽이다.

## 참고: 기준 코인 59개 (이미 본 데이터)

- 전체 적중률: 4시간 52.52% 대 52.09%, 8시간 52.75% 대 52.01%.
- 같은 건수 선택: 4시간 55.82% 대 55.41%, 8시간 55.75% 대 55.77%.

## 해석

- 순위 특징은 확률의 정확도를 뚜렷하게 올렸다. 로그손실 개선의 구간이 0에서 멀고, 최근 구간에서 더 컸다. 전체 적중률은 0.4 ~ 0.7%p 올랐다.
- 확신이 가장 큰 예측의 적중률은 오르지 않았다. X2는 통과했지만 차이가 0.1 ~ 0.2%p라 우연과 구별되지 않는다. 탐색에서 본 +0.6%p는 예상대로 줄었다.
- 고른 예측 1건당 평균 상대수익은 순위 모델 쪽이 더 작다(4시간 +0.040% 대 +0.074%, 8시간 +0.095% 대 +0.159%). 적중률이 같아도 덜 움직이는 예측을 더 많이 고른다는 뜻이다. 수익성이 나아졌다는 근거는 없다.

## 이 결과로 바꾼 것

- 실시간 예측기의 시장 대비 모델에 순위 특징 7개를 넣었다(특징 22개).
- 예측 기록에 모델 버전을 남기고, 화면의 시장 대비 채점은 바꾼 뒤의 예측만 센다.
- 방향 예측(오를까 내릴까) 모델은 바꾸지 않았다. v11은 방향 예측을 시험하지 않았다.
