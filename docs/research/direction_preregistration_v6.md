# 방향 예측 모델 사전 등록 (v6)

작성 2026-11-11. 새 코인 데이터와 외부 데이터를 내려받기 전에 작성했다.

## 배경

- v3 모델의 4시간 적중률은 개발 구간에서 52.6%였다. 우위의 근원은 단기 반전이고, 해마다 약해지고 있다.
- 2026-11-11에 이미 본 데이터(원래 코인 10개, 2022-01 ~ 2026-08)로 여러 변형을 탐색했다.
  - 모델 손질(학습 기간, 규제 강도, 코인별 모델, 비선형)은 효과가 없었다.
  - 확신 상위 10%(55.7%)와 8~12시간 예측은 조금 나아 보였다. 하지만 같은 데이터에서 본 것이라 증거가 아니다.
- 사용자는 남은 방법을 모두 시도하라고 했다.

v6는 그 방법들을 **한 번도 보지 않은 코인 50개**에서 시험한다. 원래 10개 코인의 결과는 이미 봤으므로 판정에 쓰지 않는다.

## 구간

| 용도 | 기간 (UTC) |
|---|---|
| 학습 시작 | 2021-01-01 (지표 계산용 데이터는 2020-09부터) |
| 채점 | 2022-01-01 ~ 2026-08-06 미만 |
| 최종 확인 | 2026-08-06 ~ 2026-11-06 미만. 사용자 승인 뒤 1회. 개발 코드는 이 구간을 내려받지 않는다 |

## 새 코인 50개를 고르는 규칙

- 바이낸스 USDT 무기한 선물 가운데 지금 거래 중이고, 2023-01-01 전에 상장된 것.
- 원래 10개와 스테이블코인(USDC, FDUSD, TUSD, BUSD)은 뺀다.
- 고르는 시점의 24시간 거래대금 상위 50개.
- 목록은 내려받기 전에 `replay_data/h4/v6_symbols.json`에 저장한다.

## 공통 설정

v3와 같다. 특징 13개, L2 로지스틱(λ = 10), 표준화 후 ±5 자르기, 매달 1일 재학습, 정답이 그 시점 전에 끝난 표본만 학습. BTC 특징은 BTC 값을 쓴다. 비용은 왕복 0.20%(2배 시험은 0.40%)이고, 보유 중 자금조달비를 반영한다. 구간 추정은 달 단위 복원 추출(2,000회, 시드 7)이다.

## 시험

### T1. 옮겨 가는가 (4시간)

원래 10개 코인으로만 학습한 모델을 새 코인 50개에 적용한다.

- T1a: 기준선(학습 구간의 상승 비율) 대비 로그손실 개선의 95% 구간 하한이 0 초과.
- T1b: 적중률이 "항상 오른다"와 "항상 내린다" 중 높은 쪽보다 높다.

### T2. 확신이 클 때만 (상위 10%)

- 문턱은 재학습 때마다 정한다. 학습 표본에서 |p − 0.5|의 90번째 백분위수다. 그 달에는 이 값 이상인 예측만 고른다.
- 새 코인에서 고른 예측에 대해 다음을 모두 요구한다.
  - T2a: 적중률의 95% 구간 하한이 50% 초과.
  - T2b: 적중률이 전체 예측의 적중률보다 높다.
  - T2c: 고른 예측 1건당 평균 순수익이 비용 1배와 2배에서 모두 0 초과. 순수익 = 방향 × 수익률 − 자금조달비 − 왕복 비용.

### T3. 예측 기간 8시간과 12시간

T1과 T2를 예측 기간 2봉(8시간)과 3봉(12시간)에 대해 똑같이 적용한다. 모든 봉에서 예측하므로 보유 기간이 겹친다. 그래서 자금 곡선은 만들지 않고 건당 평균만 본다.

### T4. 넓게 학습하면 원래 코인이 나아지는가

코인 60개 전체로 학습한 모델과 원래 10개로 학습한 모델을, 원래 10개 코인의 같은 행에서 비교한다(4시간).

- 통과: 로그손실 개선의 95% 구간 하한이 0 초과. 통과하면 이후 학습에 60개를 쓴다.

### T5. 외부 정보

원래 10개 코인, 4시간. v3 특징에 아래 6개를 더한 모델과 v3를 같은 행에서 비교한다.

| 특징 | 정의 | 쓸 수 있는 시점 |
|---|---|---|
| spx_r | S&P 500의 직전 거래일 종가 로그수익률 | 그 거래일 다음 날 00:00 UTC부터 |
| vix | 직전 거래일 VIX 종가의 로그 | 위와 같음 |
| vix_change | vix에서 그 전 거래일 값을 뺀 값 | 위와 같음 |
| dxy_r | 달러 지수(DXY)의 직전 거래일 종가 로그수익률 | 위와 같음 |
| dvol | 데리비트 BTC 변동성 지수의 로그. 봉 마감 직전 1시간 봉의 종가 | 봉 마감 시점 |
| dvol_change | dvol에서 6봉 전 dvol을 뺀 값 | 봉 마감 시점 |

- 통과: v3 대비 로그손실 개선의 95% 구간 하한이 0 초과.
- 뉴스는 다루지 않는다. 과거 뉴스를 미래 정보 없이 재현할 방법이 없기 때문이다.

## 후보 선정과 최종 확인

- 후보는 예측 기간 4시간, 8시간, 12시간 가운데 새 코인에서 T1a, T1b, T2a, T2b, T2c를 모두 통과한 것이다.
- 여럿이면 비용 2배에서 건당 평균 순수익이 가장 높은 것 1개를 고른다. 없으면 결론은 NO_VERIFIED_DIRECTION_EDGE다.
- 후보의 학습 코인은 T4 결과를, 특징은 T5 결과를 따른다.
- 최종 확인은 2026-08-06 ~ 2026-11-06, 코인 60개, 사용자 승인 뒤 1회다. 아래를 모두 만족하면 PASS_FOR_PAPER다.
  - 고른 예측 100건 이상
  - 고른 예측의 적중률 50% 초과
  - 건당 평균 순수익 0 초과(비용 1배)
  - 전체 예측의 기준선 대비 로그손실 개선 0 초과

## 알고 있는 한계

- 새 코인을 오늘의 거래대금으로 골랐다. 살아남아 지금 거래가 많은 코인만 들어가므로 생존 편향이 있다.
- 새 코인은 원래 코인과 같은 기간, 같은 시장을 겪었다. 완전히 독립된 시험이 아니다.
- 작은 코인의 실제 슬리피지는 가정(한쪽 0.05%)보다 클 수 있다.
- 외부 데이터의 과거 값은 나중에 수정된 값일 수 있다. 실시간으로 쓰려면 다른 출처가 필요하다.
