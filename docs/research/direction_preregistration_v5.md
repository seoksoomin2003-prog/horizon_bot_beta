# 방향 예측 모델 사전 등록 (v5)

작성 2026-11-08. 새 데이터를 내려받거나 결과를 보기 전에 작성했다.

## 배경

- v3에서 D4는 개발 구간에서 작은 방향 정보를 보였다.
- v4 검증(2025-11-06 ~ 2026-08-06)에서는 그 정보가 재현되지 않았다. 두 후보 모두 FAIL이고, 그 구간은 소진됐다.
- v3의 특징 13개는 모두 가격, 거래량, 자금조달 요율에서 나온다.

v5는 모델을 바꾸지 않고 **새 종류의 정보**를 더한다. 그 정보가 방향을 맞힐 확률을 실제로 올리는지가 핵심 질문이다.

1. **매수 체결 비중:** 시장가로 사들인 거래량이 전체 거래량에서 차지하는 비율이다. 누가 급하게 사거나 파는지를 보여 준다.
2. **베이시스:** 무기한 선물 가격이 현물 지수보다 얼마나 비싼지(프리미엄 지수)다. 레버리지 매수가 얼마나 몰렸는지를 보여 준다.

미결제약정과 롱숏 비율은 바이낸스가 최근 30일치만 주므로 쓰지 않는다. 새 라이브러리는 쓰지 않는다.

## 특징 (v3의 13개 + 새 5개 = 18개)

새 특징은 모두 각 4시간봉 마감 시점까지의 데이터로 계산한다.

14. **taker_1:** 직전 1봉의 매수 체결 거래량 ÷ 전체 거래량 − 0.5

17. **basis:** 직전 1봉 프리미엄 지수 종가
18. **basis_change:** basis에서 6봉 전 basis를 뺀 값

다음은 모두 v3·v4와 같다.
- 모델: L2 로지스틱, λ = 10. 학습 구간 기준으로 표준화하고 ±5에서 자른다.
- 매달 1일에 다시 학습하고, 정답이 그 시점 전에 끝난 표본만 쓴다.
- 코인 10개, 후보 D4(4시간)와 D24(하루, 00:00 UTC에만).
- 거는 규칙: 예상 이익 0.5% 초과일 때만 건다(v4 규칙).
- 자금: 코인당 10%, 손절 없음, 자금조달비 반영, 한쪽 비용 0.10%(2배 시험 0.20%), 시작 자금 1,000 USDT.

새 특징이 빈 행(상장 직후 등)은 v5와 비교 대상인 v3 모두에서 뺀다. 두 모델은 같은 행으로 비교한다.

## 개발 구간 관문 (모두 통과해야 후보 자격)

0. **새 정보의 기여:** 같은 행에서 v5의 로그손실이 v3보다 낮다. 달 단위 복원 추출(2,000회, 시드 7)로 구한 개선량 95% 구간의 하한이 0 초과. **가장 중요한 관문이다.**
1. **정보:** v5의 로그손실이 기준선(학습 구간의 상승 비율)보다 낮다. 95% 구간 하한 0 초과.
2. **최근 구간:** 2025-11-06 ~ 2026-08-06(v3가 실패한 구간)에서 v5의 기준선 대비 로그손실 개선이 0보다 크다(점추정).
3. **적중:** 건 예측의 적중률 95% 구간 하한이 50% 초과.
4. **비용:** 순수익이 비용 1배와 2배에서 모두 0 초과.
5. **해마다:** 2022 ~ 2026(2026은 8월 5일까지) 5개 해 중 4개 이상에서 순이익. 가장 좋은 해를 빼도 로그수익 합이 0 초과.
6. **낙폭:** 최대 낙폭 30% 이하.
7. **표본:** 건 횟수 300회 이상.

통과 후보가 없으면 결론은 NO_VERIFIED_DIRECTION_EDGE다. 최종 확인 구간은 쓰지 않는다. 둘 다 통과하면 비용 2배 순수익이 높은 쪽 1개를 올리고, 확인 실행 여부는 사용자가 정한다.

## 최종 확인 판정 (등록만 해 둔다)

- **PASS_INFO:** 다음 둘을 모두 만족한다.
  - (a) 기준선 대비 로그손실 개선 > 0
  - (b) 적중률 > max(항상 오른다, 항상 내린다)의 적중률
- **PASS_FOR_PAPER:** PASS_INFO이면서, 건 횟수 20회 이상, 비용 1배·2배 순수익 > 0, 최대 낙폭 30% 이하.

PASS_FOR_PAPER는 실거래 근거가 아니라 가상 매매로 넘어갈 자격일 뿐이다.
